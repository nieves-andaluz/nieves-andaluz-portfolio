# Portafolio web — edición y publicación

## Archivos

- `index.html`: web bilingüe editable con trayectoria, formación, herramientas y casos de trabajo.
- `linkedin-launch.md`: borrador de lanzamiento en inglés y español con el enlace público.
- `ai-quality-audit.html`, `compliance-audit.html` y `customer-operations-workflow.html`: páginas visuales bilingües para las muestras.
- `samples/*.html` y `samples/*.md`: fuentes locales editables de las muestras reconstruidas.

La web pública enlaza las tres páginas de muestra desde la raíz del repositorio. Las fuentes Markdown permanecen disponibles para editarlas.

## Integridad de las muestras

Las responsabilidades y los puestos del portafolio se basan en la experiencia indicada en el CV y el perfil. Las muestras son demostraciones reconstruidas para enseñar el método de trabajo: los escenarios y hallazgos son ficticios, no informes reales ni entregables de empleadores o clientes. No contienen datos confidenciales ni resultados atribuidos a empresas.

## Revisar y editar

Revisa el nombre, el titular, la ubicación en Madrid, el correo y el enlace a LinkedIn. Comprueba fechas, empresas, descripciones, formación, herramientas e idiomas frente a tu CV actualizado. No he añadido el teléfono del CV.

La web no necesita herramientas de compilación ni librerías externas. Abre `index.html` en un navegador para previsualizarla. El botón `ES / EN` cambia el idioma y recuerda la preferencia en ese navegador.

## Publicación

El portafolio ya está publicado en [GitHub Pages](https://nieves-andaluz.github.io/nieves-andaluz-portfolio/). El repositorio público es [nieves-andaluz-portfolio](https://github.com/nieves-andaluz/nieves-andaluz-portfolio).

Para actualizarlo, edita `index.html` y las tres páginas HTML de muestra en la raíz del repositorio; después guarda los cambios en GitHub. Revisa el texto de `linkedin-launch.md` antes de compartirlo.
